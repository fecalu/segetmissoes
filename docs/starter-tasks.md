# Tarefas iniciais sugeridas

Esta lista ajuda a simular a chegada de um novo desenvolvedor ao projeto.

## Tarefa 1: revisar textos do fluxo do motorista

Objetivo: conferir se os textos estao claros para motoristas idosos.

Tipo: frontend

Validacao:

- Abrir tela do motorista.
- Percorrer fluxo de iniciar missao.
- Percorrer fluxo de finalizar missao.
- Confirmar se os textos estao simples e diretos.

## Tarefa 2: melhorar exibicao de missoes pendentes no admin

Objetivo: destacar missoes com dados administrativos pendentes.

Tipo: frontend/backend

Validacao:

- Criar missao.
- Conferir se aparece como pendente no painel administrativo.
- Preencher destino, setor e solicitante.
- Conferir se deixa de aparecer como pendente.

## Tarefa 3: revisar relatorio PDF de missoes

Objetivo: garantir que relatorios vazios e relatorios com dados sejam gerados corretamente.

Tipo: backend/frontend

Validacao:

- Gerar relatorio para um dia sem missoes.
- Gerar relatorio para um dia com missoes.
- Conferir download e conteudo do PDF.

## Tarefa 4: documentar regras de status de veiculos

Objetivo: registrar claramente quando um veiculo fica disponivel, em missao, bloqueado, oficina, patio ou aguardando realocacao.

Tipo: docs/regra de negocio

Validacao:

- Documento revisado.
- Regras compreensiveis para area administrativa e TI.
